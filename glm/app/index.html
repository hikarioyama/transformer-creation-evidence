KV caching: when the model generates token after token, the Keys and Values of past positions never change — they can be cached and reused. Then each new token only computes its own Q, K, V and one attention row, instead of re-running the whole sequence.

Below, the app runs both paths over the current sequence — full recompute vs. incremental with cache — and compares every logit and probability.

Watch a tiny Transformer think — in 3D, with real math

This is an educational toy model: a decoder-only Transformer small enough to show every number. It was trained once, offline, on a toy language — then its weights were frozen into this page. Everything you see is real inference running in your browser: no training, no APIs, the math implemented from scratch in plain JavaScript.

the toy language's one rule: next token = (token one step back) + 1, mod 16
  • Step through the 15 computation stages with the left panel (or arrow keys).
  • Drag to orbit, scroll to zoom. Click token chips to select a position.
  • Edit the sequence in the bottom bar; toggle KV caching and let it generate.
  • Every slab, arc, bar and table shows actual computed values — nothing is faked.

Specs: 2 layers × 2 heads, hidden size 16, vocabulary 16, context 16, GELU MLPs, pre-LayerNorm, learned positions. Weights: trained with numpy (gradient-checked), exported as exact float64 — see tools/train.py.
