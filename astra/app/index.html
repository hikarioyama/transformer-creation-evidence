MODEL CARD / EDUCATIONAL TOY
Small enough to inspect.
Real enough to explain.
This is a genuine causal, decoder-only Transformer with 2 pre-normalized blocks, 2 heads per block, hidden width 16, head width 8, and vocabulary size 16. Its deterministic random weights have never been trained. Predictions are arbitrary, not evidence of understanding.
The architecture
Token embedding + sinusoidal position → [LayerNorm → causal multi-head attention → residual addition → LayerNorm → 16–32–16 GELU MLP → residual addition] × 2 → final LayerNorm → untied vocabulary projection → softmax.
No biases, dropout, or learned normalization parameters. LayerNorm uses population variance, ε = 10⁻⁵, γ = 1, β = 0. GELU uses the standard tanh approximation. Context is limited to 12 tokens for readability; no sliding window. <bos> and <eos> are ordinary toy vocabulary entries, not automatic control tokens.
Reproducibility
Seed 20250308, Mulberry32 PRNG. Embeddings use uniform [−0.65, 0.65]. Projection weights use Xavier uniform √(6 / (fan-in + fan-out)). All operations are hand-written JavaScript Float64. No external services or runtime downloads.
How to read the scene
Eight stations show representative tensors along the forward pass, with the current operation replacing its station. The whole trace is computed immediately; stepping reveals it, rather than pretending the animation is a GPU. Token 0 is the bottom tile. Features 0–15 run across each 4 × 4 tile. Signed color uses tanh(value / 2), while height uses its magnitude; output probabilities use their value directly. Attention arcs connect key positions to the selected query; opacity is proportional to actual attention probability. The numeric inspector is authoritative.
KV caching
At each layer the decoder saves past keys and values. Appending a token computes only its new row with its absolute position, attending to saved K/V. Editing a prefix invalidates that position and all later positions. The audit checks every position’s logits and probabilities against a full causal forward pass with tolerance 10⁻¹⁰.
